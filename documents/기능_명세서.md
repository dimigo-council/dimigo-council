# 학생회 인트라넷 플랫폼 기능 명세서

## 1. 개요

이 문서는 현재 Figma에 설계된 화면을 기준으로 기능을 정리한다. 화면에 있는 값(이름, 건수, 날짜 등)은 예시 데이터이므로 명세에 포함하지 않는다. 화면만으로 정할 수 없는 내용은 7장에 따로 적는다.

### 사용자

| 사용자 | 설명 |
| --- | --- |
| 방문자 | 로그인하지 않은 사용자. 랜딩 화면을 본다. |
| 학생 | 설문 참여, 건의 제출, 공개된 안건과 활동 기록 확인을 한다. |
| 학생회 | 안건, 설문, 건의, 업무, 보고서를 관리한다. |

### 메뉴 구성

| 사용자 | PC | 모바일 |
| --- | --- | --- |
| 방문자 | 홈, 안건, 설문, 건의함, 활동 기록, 로그인, 회원가입 | 미설계 |
| 학생 | 홈, 안건, 설문, 건의함, 활동 기록 | 홈, 안건, 설문, 건의함, 활동 기록 |
| 학생회 | 홈, 안건, 설문, 건의함, 업무, 보고서 | 홈, 안건, 설문, 업무, 보고서 |

PC 상단 메뉴의 학생과 학생회 화면에는 검색, 알림, 프로필(이름과 소속)이 표시된다. 프로필의 두 번째 줄은 학생회는 부서와 직책, 학생은 학년과 반이다.

### 화면 현황

| 사용자 | PC | 모바일 |
| --- | --- | --- |
| 공통 | 랜딩 | 없음 |
| 학생 | 홈, 안건 상세, 설문, 설문 참여, 건의함, 활동 기록 목록, 활동 기록 | 홈, 안건 상세, 설문, 설문 참여, 건의함(작성), 활동 기록 목록, 활동 기록 |
| 학생회 | 홈, 안건 상세, 안건 등록, 설문, 설문 만들기, 설문 결과, 건의함, 업무, 업무 추가, 보고서 작성, 보고서 검토 | 안건 등록, 설문 만들기, 업무, 업무 추가, 보고서 검토 |

## 2. 공통 규칙

### 공개 범위

| 대상 | 선택지 | 내용 |
| --- | --- | --- |
| 안건 | 전체 공개 | 모든 학생이 추진 과정과 결과를 볼 수 있다. |
| 안건 | 학생회 내부 | 학생회 구성원만 볼 수 있다. |
| 안건 | 비공개 | 책임자와 담당 부서만 볼 수 있다. |
| 보고서 | 전체 공개 | 모든 학생이 볼 수 있다. |
| 보고서 | 학생회 내부 | 학생회 구성원만 볼 수 있다. |
| 보고서 | 비공개 | 작성자와 담당 부서만 볼 수 있다. |
| 건의 | 전체 공개 | 다른 학생도 건의 내용과 처리 결과를 볼 수 있다. 이름은 공개되지 않는다. |
| 건의 | 학생회만 | 학생회만 볼 수 있다. |

### 상태값

| 대상 | 상태 |
| --- | --- |
| 안건 | 검토 중, 추진 중, 완료, 보류 |
| 건의(학생회 화면) | 접수, 검토 중, 안건 등록, 반려 |
| 건의(학생 화면) | 접수, 안건 등록, 반영 완료, 반려 |
| 건의 처리 단계 | 접수, 검토, 안건 등록, 반영 |
| 설문 | 진행 중(마감까지 남은 일수 표시), 예정, 마감 |
| 업무 | 할 일, 진행 중, 검토 요청, 완료 |
| 보고서 | 작성 중, 검토 요청, 게시 |

## 3. 랜딩

| ID | 기능 | 사용자 | 플랫폼 | 상세 |
| --- | --- | --- | --- | --- |
| LND-01 | 로그인·회원가입 진입 | 방문자 | PC | 상단 메뉴 오른쪽의 `로그인`, `회원가입` 버튼으로 이동한다. |
| LND-02 | 서비스 소개 | 방문자 | PC | 서비스 소개 문구와 `건의하기`, `진행 중인 설문` 버튼을 제공한다. |
| LND-03 | 안건 추진 현황 | 방문자 | PC | 안건 목록을 전체, 검토 중, 추진 중, 완료로 나누어 보여 주고 `전체 보기`로 이동한다. |
| LND-04 | 처리 과정 안내 | 방문자 | PC | 건의가 접수, 검토 중, 추진 중, 완료를 거치는 과정을 안내한다. |
| LND-05 | 역할 안내 | 방문자 | PC | 학생(설문 참여, 상시 건의, 활동 확인)과 학생회(안건 관리, 업무 배정, 보고서)의 기능을 안내한다. |

## 4. 홈

| ID | 기능 | 사용자 | 플랫폼 | 상세 |
| --- | --- | --- | --- | --- |
| HOM-01 | 학생 인사와 요약 | 학생 | PC·모바일 | 이름과 함께 참여할 수 있는 설문 수, 답변이 달린 내 건의 수를 보여 준다. `건의하기`로 이동한다. |
| HOM-02 | 안건 추진 현황 | 학생 | PC·모바일 | 안건의 상태, 제목, 부서, 연계 정보, 날짜를 보여 준다. PC는 상태 필터와 `전체 보기`를 제공한다. |
| HOM-03 | 마감 임박 설문 | 학생 | PC·모바일 | 남은 일수, 응답 방식, 문항 수를 보여 주고 `참여하기`로 이동한다. PC는 참여율도 보여 준다. |
| HOM-04 | 내 건의 요약 | 학생 | PC | 내 건의의 제목, 상태, 담당 부서, 날짜를 보여 주고 `건의함`으로 이동한다. |
| HOM-05 | 학생회 인사와 요약 | 학생회 | PC | 오늘 확인할 업무 수와 새로 접수된 건의 수를 보여 준다. `설문 만들기`, `안건 등록`으로 이동한다. |
| HOM-06 | 주요 지표 | 학생회 | PC | 진행 중인 설문, 처리 대기 건의, 추진 중인 안건, 나의 업무 수와 변화량을 보여 준다. |
| HOM-07 | 안건 추진 현황 | 학생회 | PC | HOM-02와 같은 목록을 보여 준다. |
| HOM-08 | 마감 임박 설문 | 학생회 | PC | HOM-03과 같은 카드를 보여 준다. |
| HOM-09 | 나의 업무 | 학생회 | PC | 내 업무를 체크리스트와 마감일로 보여 주고 `업무 보드`로 이동한다. |

## 5. 기능별 명세

### 5.1 안건

| ID | 기능 | 사용자 | 플랫폼 | 상세 |
| --- | --- | --- | --- | --- |
| AGD-01 | 안건 등록 | 학생회 | PC·모바일 | 안건 제목, 제안 배경(모바일은 제안 출처), 담당 부서, 책임자, 공개 범위를 입력한다. PC는 검토 내용과 첫 추진 기록 제목도 입력한다. |
| AGD-02 | 임시 저장 | 학생회 | PC | 등록 전 안건을 임시 저장한다. |
| AGD-03 | 공개 전 안내 | 학생회 | PC·모바일 | 등록 화면에서 개인정보와 내부 논의 포함 여부를 확인하도록 안내한다. |
| AGD-04 | 안건 조회 | 학생, 학생회 | PC(학생회), PC·모바일(학생) | 안건 번호, 제목, 상태, 담당 부서, 책임자, 등록일, 연계 건의와 공감 수를 보여 준다. |
| AGD-05 | 추진 이력 | 학생, 학생회 | PC·모바일 | 건의, 회의, 협의, 진행 중, 보고 유형의 기록을 시간순으로 보여 준다. 회의록과 보고서로 연결할 수 있다. 예정된 단계도 표시한다. |
| AGD-06 | 기록 추가 | 학생회 | PC | 안건 상세에서 `기록 추가`로 추진 이력을 남긴다. |
| AGD-07 | 업무 배정 | 학생회 | PC | 안건 상세에서 `업무 배정`을 실행한다. 관련 업무의 완료 수, 담당자, 완료 여부를 보여 준다. |
| AGD-08 | 공개 범위 변경 | 학생회 | PC | 안건 상세에서 공개 범위를 선택한다. 책임자만 변경할 수 있다. |
| AGD-09 | 연결된 설문 | 학생, 학생회 | PC·모바일 | 안건과 연결된 설문의 시작 시점, 응답 방식, 문항 수, 상태를 보여 준다. |
| AGD-10 | 공유 | 학생, 학생회 | PC | 안건 상세에서 `공유`를 제공한다. |

### 5.2 설문

| ID | 기능 | 사용자 | 플랫폼 | 상세 |
| --- | --- | --- | --- | --- |
| SRV-01 | 설문 목록 | 학생, 학생회 | PC·모바일 | 진행 중, 예정, 마감 수를 보여 주고 카드에 상태, 응답 방식, 문항 수, 제목, 설명을 표시한다. PC는 참여율도 표시한다. |
| SRV-02 | 검색과 정렬 | 학생, 학생회 | PC | 설문 제목으로 검색하고 마감 임박순으로 정렬한다. |
| SRV-03 | 설문 참여 진입 | 학생, 학생회 | PC·모바일 | 진행 중인 설문은 `참여하기`, PC의 마감 설문은 `결과 보기`를 제공한다. |
| SRV-04 | 건의 안내 | 학생, 학생회 | PC·모바일 | 설문 목록 하단에서 `건의하러 가기`로 건의함에 연결한다. |
| SRV-05 | 설문 응답 | 학생 | PC·모바일 | 문항별로 답을 선택하고 `다음 문항`으로 진행한다. PC는 `이전`도 제공한다. |
| SRV-06 | 제출 규칙 | 학생 | PC·모바일 | 모든 문항을 완료한 뒤 답변을 확인하고 제출한다. 익명 설문에는 이름이 표시되지 않는다. |
| SRV-07 | 설문 만들기 | 학생회 | PC·모바일 | 제목, 시작일, 마감일, 응답 방식(익명 또는 실명), 문항을 입력한다. PC는 설명도 입력한다. 문항은 `문항 추가`로 늘린다. |
| SRV-08 | 임시 저장과 게시 | 학생회 | PC(임시 저장), PC·모바일(게시) | 작성 중인 설문을 임시 저장하거나 `설문 게시`로 게시한다. 시작일이 되면 학생이 참여할 수 있다. |
| SRV-09 | 설문 결과 | 학생회 | PC | 응답 기간, 응답 방식, 문항 수, 응답자 수, 참여율, 마감까지 남은 기간, 문항별 선택 비율을 보여 준다. |
| SRV-10 | 결과 활용 | 학생회 | PC | `결과 내보내기`, `안건으로 연결`을 제공한다. |

### 5.3 건의

| ID | 기능 | 사용자 | 플랫폼 | 상세 |
| --- | --- | --- | --- | --- |
| SGT-01 | 건의 작성 | 학생 | PC·모바일 | 제목, 분류, 내용, 공개 범위를 입력하고 `건의 제출하기`로 제출한다. PC 기준 제목, 분류, 내용은 필수이고 내용은 1000자까지 입력한다. |
| SGT-02 | 분류 | 학생 | PC | 시설, 급식, 학습, 행사, 기타 중에서 선택한다. |
| SGT-03 | 익명 제출 | 학생 | PC·모바일 | 익명으로 제출을 켜면 학생회 구성원에게도 작성자가 표시되지 않는다. |
| SGT-04 | 내 건의 | 학생 | PC | 내 건의를 전체, 처리 중, 완료로 나누어 보여 준다. |
| SGT-05 | 처리 과정과 답변 확인 | 학생 | PC | 건의 번호, 처리 단계별 날짜, 담당 부서의 답변을 보여 주고 `연결된 안건 보기`로 이동한다. 반려된 건의는 사유를 확인할 수 있다. |
| SGT-06 | 건의 목록 | 학생회 | PC | 전체, 접수, 검토 중, 안건 등록, 반려로 나누어 상태, 제목, 분류, 학년, 공감 수, 접수일을 표 형식으로 보여 준다. |
| SGT-07 | 건의 상세 | 학생회 | PC | 목록 옆에서 번호, 접수일, 분류, 학년, 익명 여부, 공감 수, 내용을 보여 준다. |
| SGT-08 | 담당 부서 지정 | 학생회 | PC | 건의를 처리할 부서를 선택한다. |
| SGT-09 | 답변 | 학생회 | PC | 답변을 작성해 `답변 보내기`로 보낸다. 답변은 건의한 학생에게만 보인다. |
| SGT-10 | 안건 등록과 반려 | 학생회 | PC | `안건으로 등록` 또는 `반려하기`로 건의를 처리한다. |

| RPT-04 | 공개 전 확인 | 학생회 | PC | 개인정보(이름, 학번, 연락처) 미포함, 내부 논의 미포함, 첨부파일 공개 범위를 확인한다. 모든 항목을 확인해야 전체 공개로 게시할 수 있다. |
| RPT-05 | 임시 저장과 검토 요청 | 학생회 | PC | `임시 저장` 또는 `검토 요청`을 실행한다. |
| RPT-06 | 보고서 검토 | 학생회 | PC·모바일 | 요청 부서와 작성자, 본문 요약, 요청 공개 범위를 보여 준다. PC는 첨부파일별 공개 범위와 연결된 항목도 보여 준다. |
| RPT-07 | 공개 전 검토 | 학생회 | PC·모바일 | 개인정보, 내부 논의, 첨부파일별 공개 범위를 체크박스로 확인한다. 모두 확인하기 전에는 `공개 승인`이 비활성화된다. PC는 검토 의견을 표시한다. |
| RPT-08 | 승인과 수정 요청 | 학생회 | PC·모바일 | `공개 승인` 시 학생 화면에 공개되고, `수정 요청` 시 작성자에게 돌아간다. |

## 6. 기능 간 연결

| 시작 | 동작 | 결과 |
| --- | --- | --- |
| 건의 | 학생회가 `안건으로 등록` | 안건이 만들어지고 건의 번호와 공감 수가 연계된다. 학생은 `연결된 안건 보기`로 이동한다. |
| 설문 결과 | 학생회가 `안건으로 연결` | 설문 결과가 안건과 연결된다. |
| 안건 | 학생회가 `업무 배정` | 업무가 안건에 연결되어 안건 상세의 관련 업무에 표시된다. |
| 업무 | 학생회가 `보고서 작성` | 보고서를 작성하고 안건, 업무, 설문을 연결한다. |
| 보고서 | 작성자가 `검토 요청`, 검토자가 `공개 승인` | 학생의 활동 기록에 게시된다. |
| 보고서 | 검토자가 `수정 요청` | 작성자에게 돌아간다. |

## 7. 확인이 필요한 사항

### 설계되지 않은 화면

| 항목 | 현재 상태 |
| --- | --- |
| 로그인, 회원가입 | 랜딩에 버튼만 있고 화면이 없다. |
| 안건 목록 | 메뉴와 `전체 보기`는 있으나 PC·모바일 모두 목록 화면이 없다. |
| 학생회 보고서 목록 | 메뉴는 있으나 작성과 검토 화면만 있다. |
| 학생용 설문 결과 | 마감 설문에 `결과 보기`가 있으나 학생회용 결과 화면만 있다. |
| 설문 답변 확인과 제출 | 확인 후 제출한다고 안내하지만 해당 화면이 없다. |
| 검색, 알림 | 상단 메뉴에 아이콘만 있다. |
| 전체 공개 건의 열람과 공감 | 다른 학생이 볼 수 있다고 안내하고 공감 수도 표시하지만, 열람 화면과 공감 동작이 없다. |
| 모바일 랜딩 | 없음 |
| 모바일 학생회 홈, 안건 상세, 설문, 설문 결과, 건의함, 보고서 작성 | 없음 |
| 모바일 학생 내 건의 | 건의 작성만 있고 목록과 처리 현황이 없다. |

### 정해야 할 규칙

| 항목 | 현재 화면 | 결정할 내용 |
| --- | --- | --- |
| 건의 분류 | 작성 화면은 시설, 급식, 학습, 행사, 기타이고, 학생회 건의함에는 생활, 복지도 나온다. | 분류 목록을 하나로 정한다. |
| 건의 상태 | 학생회 화면과 학생 화면의 상태값이 다르고, 처리 단계 이름도 따로 있다. | 상태값과 화면별 표시 이름을 정한다. |
| 익명 건의 | 작성자가 표시되지 않는다고 안내하지만 학생회 건의함에 학년이 표시된다. | 익명 건의에 학년을 보여 줄지 정한다. |
| 안건 필터 | 필터에 보류가 없지만 보류 상태 안건이 목록에 나온다. | 보류 필터를 추가할지 정한다. |
| 학생회의 설문 참여 | 학생회 설문 목록에도 `참여하기`가 있다. | 학생회 구성원의 참여 방식과 버튼 구성을 정한다. |
| 방문자 접근 범위 | 랜딩에 안건 현황과 `건의하기`, `진행 중인 설문`이 있고 메뉴도 표시된다. | 로그인 없이 볼 수 있는 범위와 버튼 동작을 정한다. |
| 공개 범위 권한 | 안건은 책임자만 변경할 수 있다고 표시되어 있다. | 건의와 보고서의 공개 범위 변경 권한을 정한다. |
| 보고서 검토자 | 검토 권한을 가진 사람이 화면에 나타나 있지 않다. | 검토와 공개 승인 권한을 정한다. |
| 설문 문항 유형 | 단일 선택만 설계되어 있다. | 지원할 문항 유형을 정한다. |
| 예시 데이터 불일치 | 안건 #024의 책임자가 화면에 따라 조원 또는 김하린으로 표시된다. | Figma 예시 데이터를 맞춘다. |
