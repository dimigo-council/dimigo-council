# 학생회 플랫폼 기능 명세서

## 1. 개요

### 사용자 구분

방문자, 학생, 학생회로 구분된다.
이 문서에서 `질의`는 `질문과 건의`의 줄임말이다.

| 사용자 | 설명 |
| --- | --- |
| 방문자 | 로그인하지 않은 사용자. 랜딩 화면만 공개되어있다. |
| 학생 | 설문 참여, 질의 제출, 공개된 활동과 PDF 활동 기록 확인을 한다. |
| 학생회 | 활동, 설문, 질의, 업무를 관리하고 PDF 활동 기록을 열람한다. |

### GNB

GNB는 권한에 따라 표시되는 메뉴가 다르다.

| 사용자 | GNB 구성 |
| --- | --- |
| 학생 | 홈, 활동, 설문, 질문과 건의, 활동 기록 |
| 학생회 | 홈, 활동, 업무, 설문, 질문과 건의, 활동 기록 |

Actions는 PC에서 GNB 오른쪽에 있는 버튼 그룹으로, 검색, 알림, 프로필이 표시된다.
방문자는 학생이 보는 GNB가 표시되며, 각 메뉴를 들어가게 되면 로그인이 필요하다는 메시지와 함께 로그인, 회원가입 버튼이 표시된다.
즉, 방문자는 GNB에 있는 메뉴에 엑세스가 불가능하다.
방문자는 Actions 대신 로그인과 회원가입 메뉴가 표시된다.

Note: 모바일과 PC의 GNB는 일치해야 한다.
      모바일은 GNB가 아래쪽 배너에 위치한다.

### 화면 현황

| 사용자 | PC | 모바일(미제작) |
| --- | --- | --- |
| 공통 | 랜딩, 로그인, 회원가입 | 없음 |
| 학생 | 홈, 활동 상세, 설문, 설문 참여, 질의함, 질의함 / 작성 중, 활동 기록 목록, 활동 기록 | 홈, 활동 상세, 설문, 설문 참여, 질의함(작성), 활동 기록 목록, 활동 기록 |
| 학생회 | 홈, 활동 상세, 활동 등록, 활동 등록 / 직접 제안, 설문, 설문 만들기, 설문 결과, 질의함, 업무, 업무 추가, 업무 상세(수정 중, 완료), 활동 기록 목록, 활동 기록 | 활동 등록, 설문 만들기, 업무, 업무 추가 |

위 표는 Figma의 화면 종류를 현재 기능명으로 표기한 것이다. 모바일 화면은 모두 미제작이다. 활동 기록 작성·검토 화면과 편집형 활동 기록 화면은 구현 대상에서 제외한다. 활동 기록은 정적 PDF 열람으로 대체한다.

## 2. 공통 규칙

### 공개 범위

| 대상 | 선택지 | 내용 |
| --- | --- | --- |
| 활동 | 전체 공개 | 모든 학생이 추진 과정과 결과를 볼 수 있다. |
| 활동 | 학생회 | 학생회 임원만 볼 수 있다. |
| 질의 | 전체 공개 | 모든 학생이 질의 내용과 처리 결과를 볼 수 있다. 익명으로 제출한 질의는 작성자 이름이 표시되지 않는다. |
| 질의 | 학생회만 | 학생회만 볼 수 있고 다른 학생은 볼 수 없다. |

질의의 공개 범위는 질의를 작성한 사람만 정하고 변경할 수 있다.

## 5. 기능별 명세

### 5.1 활동

활동 기능은 학생회가 활동하는 내용을 타임라인 형식으로 기록하고 대외공개하는 기능이다.

기본정보
제목, 설명, 담당 부서/담당자, 공개 범위(전체 공개/학생회), 첫 추진 기록, 연결된 질문과 건의(선택, 여러개), 등록일

이력의 기본정보
제목, 설명, 추진 날짜, 연결되는 정보, 유형(질의, 회의, 협의, 추진, 보고)

상태
검토 중, 추진 중, 완료, 보류

| ID | 기능 | 사용자 | 상세 |
| --- | --- | --- | --- |
| AGD-C1 | 활동 등록 | 학생회 | 기본 정보를 입력하여 활동을 등록할 수 있다. |
| AGD-C2 | 임시 저장 | 학생회 | 등록 중인 활동을 임시 저장한다. 임시 저장된 활동이 있으면 활동 조회 화면에서 `활동 등록` 버튼 옆에 불러오기 버튼을 표시하고, 그 버튼으로 저장한 내용을 다시 열어 이어서 작성한다. |
| AGD-C3 | 업무 배정 | 학생회 | 활동 상세에서 업무 배정 기능으로 이동하여 해당 활동에 연결된 업무를 추가한다. |
| AGD-C4 | 이력 추가 | 학생회 | 업무 기능과 연결되지 않은 이력을 추가한다. |
| AGD-D1 | 이력 삭제 | 학생회 | 추진 이력을 삭제한다. |
| AGD-R1 | 활동 조회 | 학생, 학생회 | 제목, 상태, 공개 범위, 담당 부서, 등록일을 하나의 열로 보여 준다. 상태에 따른 분류가 가능하며, 공개 범위에 따라 열람 권한을 분리한다. |
| AGD-R2 | 활동 상세 | 학생, 학생회 | 기본 정보와 활동 계획서, 추진 이력, 연결된 질문과 건의, 연결 설문을 보여 준다. |
| AGD-R3 | 활동 공유 | 학생 | 활동 상세의 `공유` 버튼으로 활동을 공유한다. |
| AGD-U1 | 공개 범위 변경 | 학생회 | 활동 상세에서 공개 범위를 변경한다. 담당자만 변경할 수 있다. |

### 5.2 업무

업무 기능은 학생회 구성원 간 업무 요청을 체계화하고 연계된 활동에 자동으로 기록하기 위한 기능이다.
업무는 대외적으로 공개되지 않는 것이 원칙이나, 연계된 활동이 전체 공개로 설정되어있으면 활동 기능과 연계하여 업무가 공개된다.
따라서 업무 기능은 공개되지 않고, 활동과 연계된 업무만 공개된다.

기본정보
제목, 연결된 활동, 배정자, 담당 부서, 담당자, 시작일, 마감일
설명이 없다. 시작일은 기본값이 오늘이다.

진행 기록의 기본정보
제목, 날짜, 상태

상태
예정됨, 진행 중, 검토 요청, 완료

진행 기록 유형
배정, 진행 중, 수정, 완료

| ID | 기능 | 상세 |
| --- | --- | --- |
| TSK-C1 | 업무 추가 | 제목, 연결된 활동, 담당 부서, 담당자, 시작일(기본값 오늘), 마감일, 초기 진행 상태를 입력해 업무를 배정한다. |
| TSK-C2 | 기록 추가 | 바뀐 내용을 한 줄로 적어 등록한다. 상태를 바꾼 기록에는 변경 후 상태를 남기고, 가장 최근에 기록된 상태를 업무의 현재 상태로 반영한다. |
| TSK-R1 | 업무 보드 | 예정됨, 진행 중, 검토 요청, 완료 열에 업무를 보드 형식으로 보여준다. 카드에는 태그, 제목, 마감일이 있다. |
| TSK-R2 | 업무 상세 | 제목, 연결된 활동, 배정자, 담당 부서, 담당자, 시작일, 마감일, 상태와 진행 기록을 보여 준다. |
| TSK-U1 | 업무 수정 | 제목, 연결된 활동, 담당자, 시작일, 마감일을 수정할 수 있다. 변경 내용은 진행 기록에 자동으로 남긴다. |

### 5.3 설문

설문 기능은 학생회가 운영하는 많은 설문들을 한데 모아, 이 플랫폼에서 바로 투표할 수 있게 하는 기능이다.

기본 정보
제목, 설명, 연결 활동(필수), 시작일, 마감일, 응답 학년(1/2/3), 학년/반 수집 여부
설문은 응답자의 이름을 수집하지 않는다.

문항의 정보
질문, 질문 형식(단일 선택, 복수 선택, 단답형, 장문형), 옵션 목록

상태
진행 중, 마감

| ID | 기능 | 사용자 | 상세 |
| --- | --- | --- | --- |
| SRV-C1 | 설문 등록 | 학생회 | 기본 정보와 문항을 입력하여 설문을 만든다. 응답할 수 있는 학년을 1, 2, 3학년 중에서 제한할 수 있다. 연결된 활동이 있어야 설문을 게시할 수 있다. |
| SRV-C2 | 임시 저장 | 학생회 | 작성 중인 설문을 임시 저장한다. 임시 저장된 설문이 있으면 설문 목록 화면에서 `설문 만들기` 버튼 옆에 불러오기 버튼을 표시하고, 그 버튼으로 저장한 내용을 다시 열어 이어서 작성한다. |
| SRV-C3 | 설문 응답 | 학생, 학생회 | 설문에 응답한다. 학생회도 학생과 같은 화면으로 응답한다. 학년/반을 수집하는 설문은 회원가입 시 해당 정보를 입력한 사람만 응답할 수 있다. |
| SRV-R1 | 설문 목록 | 학생, 학생회 | 카드에 D-n, 제목, 설명, 참여율을 표시한다. 목록 하단의 `질의하러 가기`로 질문과 건의 화면에 연결한다. |
| SRV-R2 | 설문 결과 | 학생회 | 응답 기간, 문항 수, 응답자 수, 참여율, 마감까지 남은 기간, 문항별 선택 비율을 보여 준다. |

### 5.4 질문과 건의

질문과 건의(줄여서 질의)는 학생회의 공식 입장을 묻거나 개선을 제안하고 학생회의 답변을 얻을 수 있는 기능이다.

학생이 질문과 건의를 제출하면, 접수 상태로 등록된다.
만약 개선 제안이라면, 우선 학생회가 답변을 한 후(답변 완료), 제안을 반영한 후 처리 완료로 표시한다.
만약 터무니없는 내용이라면 학생회가 답변 후 반려로 표시한다.
만약 질문이라면 학생회가 답변 후 처리 완료할 수 있다.

기본 정보
제목, 내용, 공개 범위(전체 공개/학생회만), (만약 전체 공개라면) 익명 여부

답변 정보
상태, 내용

상태
접수, 답변 완료, 반려, 처리 완료

| ID | 기능 | 사용자 | 상세 |
| --- | --- | --- | --- |
| SGT-C1 | 질문과 건의 제출 | 학생 | 제목, 내용, 공개 범위를 입력하고 `질의 제출하기`로 제출한다. 전체 공개를 선택한 경우 같은 작성 화면에서 익명 여부를 선택할 수 있으며, 익명으로 제출하면 학생회 임원에게도 작성자가 표시되지 않으며, 학생회 화면에는 작성자의 학년과 반도 표시하지 않는다. 공개 범위는 작성자만 정하고 변경할 수 있다. PC 화면에서 제목·내용은 필수이며 내용은 1000자 이내다. 제출 직후 상태는 `접수`다. |
| SGT-R1 | 내 질의 조회 | 학생 | 질의함에서 질의를 전체, 접수, 답변 완료, 처리 완료, 반려로 나누어 보여 주고, `내 질의만 보기`를 켜면 내 질의만 표시한다. 선택한 질의의 번호, 처리 단계별 날짜, 담당 부서의 답변과 반려 사유를 확인한다. 연결된 활동이 있으면 해당 활동으로 이동한다. |
| SGT-R2 | 공개 질의 조회 | 학생 | SGT-R1과 같은 질의함 화면에서 전체 공개 질의의 내용과 공개가 허용된 처리 결과를 확인한다. 별도의 공개 질의 화면은 두지 않는다. 학생은 하트 버튼으로 공감을 켜고 끌 수 있고 공감 수가 함께 표시된다. 작성자 정보는 2장의 공개 범위 규칙에 따르고, 답변의 공개 범위는 7장의 결정에 따른다. |
| SGT-R3 | 질의 목록과 상세 | 학생회 | 전체와 상태별 목록에 질의 번호, 상태, 제목, 공감 수, 접수일을 보여 준다. 선택한 질의의 내용·공개 범위·익명 여부·담당 부서를 확인하며, 공개 범위와 익명 여부에 따라 작성자 정보를 제한한다. 익명 질의는 작성자의 이름, 학년, 반을 모두 표시하지 않는다. 학생회는 질의의 공개 범위를 변경할 수 없다. |
| SGT-U1 | 질의 처리 | 학생회 | 담당 부서를 지정하고 답변을 작성해 `답변 보내기`로 보낸다. 현재 답변은 질의한 학생에게만 보인다. 답변 후에는 `답변 완료`, 질문에 대한 처리를 마치거나 제안을 반영하면 `처리 완료`, 반영하지 않을 때는 사유를 남기고 `반려하기`로 `반려` 상태로 바꾼다. |
| SGT-U2 | 활동 연결 | 학생회 | 제안을 활동으로 등록하거나 기존 활동에 연결한다. 연결된 활동은 질의 상세에서 확인할 수 있다. |

### 5.5 활동 기록

활동 기록은 사이트 관리자가 정적 파일로 배포한 공개 PDF를 학생과 학생회가 열람하는 기능이다. 학생회용 작성·업로드·검토·승인 화면이나 상태값은 두지 않는다.

기본 정보
제목, PDF 파일, 게시일

| ID | 기능 | 사용자 | 상세 |
| --- | --- | --- | --- |
| ACT-R1 | PDF 목록 | 학생, 학생회 | 정적 파일로 배포된 활동 기록 PDF의 제목과 게시일을 보여 준다. |
| ACT-R2 | PDF 열람 | 학생, 학생회 | 목록에서 선택한 PDF 파일을 보여 준다. |

## 6. 기능 간 연결

이 서비스는 기능 간 연결이 매우 밀접하고, 이 연결을 사용자가 쉽게 아는 것이 중요한 서비스이다.
사용자가 이 연결을 쉽게 파악할 수 있도록 UI적, 워딩적 요소를 잘 갖추어야 한다.

- 활동과 업무간의 관계
  활동에서 AGD-C3(업무 배정) 기능을 이용하여 해당 활동과 연결된 업무를 추가할 수 있다.
  업무에서 TSK-C1(업무 추가) 기능을 이용하여 연결할 활동을 선택할 수 있다.
  연결된 업무의 진행 기록은 활동의 추진 이력에 반영된다.
- 활동과 설문간의 관계
  설문에서 SRV-C1(설문 등록) 기능을 이용하여 연결할 활동을 선택할 수 있다.
  활동 상세에서 연결된 설문과 결과로 이동할 수 있다.
- 질문과 건의와 활동 간의 관계
  학생회가 질의 중 개선 제안을 새 활동으로 등록하거나 기존 활동에 연결할 수 있다. 활동 상세에서 연결된 질의를 확인하고, 질의 상세에서 연결된 활동으로 이동할 수 있다.

연결된 항목의 내용은 각 항목의 공개 범위와 사용자의 권한에 따라 보여 준다.
